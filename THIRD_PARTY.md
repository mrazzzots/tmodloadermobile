# Сторонние компоненты

Проект **не распространяет** файлы Terraria и tModLoader. Пользователь копирует их
из своей купленной копии игры.

Компоненты, которые собираются или подтягиваются при сборке:

| Компонент | Откуда | Лицензия |
|---|---|---|
| FNA (форк tModLoader) | github.com/tModLoader/FNA | Ms-PL |
| FNA3D, MojoShader | github.com/FNA-XNA/FNA3D | zlib |
| FAudio | github.com/FNA-XNA/FAudio | zlib |
| Theorafile (libogg/libtheora/libvorbis внутри) | github.com/FNA-XNA/Theorafile | zlib + BSD |
| SDL2 | github.com/libsdl-org/SDL | zlib |
| Vulkan-Headers | github.com/KhronosGroup/Vulkan-Headers | Apache-2.0 / MIT |
| MonoMod (RuntimeDetour, Core, Utils) | NuGet / github.com/MonoMod/MonoMod | MIT |
| Mono.Cecil | NuGet | MIT |
| LLVM libunwind (из Android NDK) | Android NDK | Apache-2.0 WITH LLVM-exception |

tModLoader распространяется под MIT вместе с отдельными Terms of Use
(github.com/tModLoader/tModLoader/blob/1.4.5/TERMS_OF_USE.md). Terraria® — проприетарная
игра и товарный знак Re-Logic, Inc.; название используется только в ссылочном смысле
(«совместимо с»).
